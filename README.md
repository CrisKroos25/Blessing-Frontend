# Inventory Management System Blessing

Sistema de gestión para un negocio de venta de arreglos y peluches.

El sistema incluye:

- Gestión de inventario
- Gestión de compras
- Gestión de ventas

---

## Tecnologías utilizadas

- React
- Vite
- React Router
- CSS Modules
- Lucide Icons

---

## Estructura del proyecto

El proyecto sigue una arquitectura basada en **features**.

features/

- inventory/
- purchases/
- sales/

Componentes reutilizables dentro de shared:
shared/

- Button
- Modal
- CardInfo
- TitleTable

Componentes que definen la estrucuta del proyecto:

layouts/

- Header
- Sidebar
- Layout principal
